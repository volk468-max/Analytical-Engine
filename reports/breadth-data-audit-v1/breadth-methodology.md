# Breadth methodology v1 — no trading model

## Universe and time
The engine consumes an explicit exchange-session calendar, stable security IDs and dated membership snapshots (effective_date, available_at, members, pit_verified). At decision time it selects only a snapshot effective on/before that day and available by the decision. Future-announced rebalances do not apply early. Each member counts once per share-class/security ID; there is no automatic company-level consolidation. A provider adapter must resolve reused tickers, IPOs, delistings, suspensions, mergers and renames using a permanent ID/security master. A renamed ticker can share the same ID only if the corporate continuity is verified.

Prototype universes are FIXED_SEVEN_SEMIS_PROXY and FIXED_ELEVEN_CURRENT_SURVIVORS_PROXY, never SOX, S&P500 or Nasdaq100. NBIS begins2024-10-21 under PR11 resumed-current-business eligibility, not a claim this is its original IPO; PLTR has pre-study history from2020-09-30. Proxy membership effective/available dates are retrospective assumptions and pit_verified=False.

## Formula and denominator
At day t, all following windows end at the completed session t unless explicitly excluded. The reference close is split-consistent price-only, not dividend-adjusted total return.

- MA50/200: SMA_n(t)=mean of n consecutive scheduled closing prices INCLUDING t. Numerator is number with close(t)>SMA_n(t), strict comparison. Denominator is number of current members with every n scheduled bars observed and available. Output both this denominator and universe_size. IPOs with insufficient history are unknown, never below-MA by default.
- Percentage=100*numerator/metric_eligible_count. *_observed fields are descriptive percentages on the valid subset. Published primary percentage is NULL unless metric_eligible_count/universe_size >= minimum_coverage; v1 fixes minimum_coverage=1.0 for QA, not a fitted risk threshold. Coverage is not equal to100% merely because the denominator shrank.
- Advance/Decline: A=#close(t)>close(t−1), D=#close(t)<close(t−1), U=ties; require both adjacent scheduled sessions. A/D excludes U mathematically, but A,D,U and eligible counts remain visible. D=0 yields NULL plus NO_DECLINERS/NO_DIRECTIONAL_MOVES, never infinity or a fabricated ratio. Coverage gate applies separately.
- New highs/lows: current intraday high strictly greater than maximum of the PRIOR252 scheduled session highs; current low strictly less than PRIOR252 lows. This requires253 bars including today. Ties do not count. The current bar is excluded from the historical comparison set. This is a fixed252-session approximation to52calendar weeks; vendors may use different windows or closing prices. Both sides may count on a large-range day; no intraday ordering is inferred.
- Breadth divergence20: index return over20 scheduled sessions >0 while pct_above_ma50(t)−pct_above_ma50(t−20)<0. Save return and percentage-point change, not a fitted score. Both dates need valid percentages and identical membership signatures; missing values or changed members yield NULL. This is a descriptive sign disagreement, not a risk/trading signal.

## Missingness, calendar, availability
Windows require every scheduled session; no forward/back fill, interpolation or bridging a missing day with older observations. Weekends/holidays appear only if explicitly supplied as sessions; production use requires an audited calendar including exceptional closures and early closes. The inherited2021–2026 calendar is reused;2020 warmup sessions inferred from archived AMD dates and NY16:00 closes are marked unverified. Positive finite high/low/close and low<=close<=high required. Reject duplicate bars and duplicate IDs; a revised provider snapshot must be selected as-of explicitly rather than silently overwrite history.

A close cannot be used before calendar close or before available_at. Timezones are required. PR11 assumes next UTC midnight for availability, not attested historical publication. Runner computes at that midnight; these rows cannot become confirmed historical evidence. Original bar publication/revision archives are absent.

## Corporate actions and eligibility
Input price_basis must explicitly be homogeneous split units. No mixing raw opens with adjusted closes. adjust_splits handles raw nominal OHLC on as-of units using only split events effective and available by decision time. Raw ratios are new shares/old shares; backward prices divide by ratio. Reverse splits work the same way. Uniform later unit scaling does not change SMA comparisons, A/D or high/low flags; this is tested, not proof of a full corporate-action audit. Dividends remain price drops in this v1 price-only calculation. For StockCharts reconciliation a separately versioned dividend-adjusted basis and vendor methodology are required; never silently switch basis. Mergers, spin-offs and ticker reuse need provider-specific identity/action verification and currently block eligibility.

historical_backtest_eligible requires verified membership history, snapshot PIT status, publication times for all relevant bars, corporate actions, calendar, stable identities AND full coverage for every metric. Proxy rows always fail these checks. This flag is a data gate, not evidence of predictive ability. No price thresholds, actions, risk states or forecasts are generated.

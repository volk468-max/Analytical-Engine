Important read-only boundary: ADC /market/history appears to be GET, but repository() constructs Database(DB_PATH), whose constructor calls init_schema(), CREATE/ALTER/CREATE INDEX and commit. Therefore this audit did NOT call live ADC history endpoints: they are not guaranteed read-only. Do not import these Database classes for a storage inspection. A future inventory should use a supplied immutable SQLite backup (mode=ro; no application initializer), read-only Postgres role, and restricted Redis ACL/metadata export. Safe infrastructure evidence contains variable NAMES only; no variable values, tokens, passwords or connection URLs.

# Решение о целесообразности данных

**Покупку сейчас не рекомендую. Рекомендую подготовить ограниченный trial для личного некоммерческого исследования, затем принять отдельное решение по его результатам.** Ни trial, ни реальные данные не проверены этим PR.

По официальным N1/N2 Platinum даёт нужные классы данных и историческую глубину для2010–2026; годовой ориентир $630, шестимесячный $346.50 (не включает Windows/cloud/налоги). Это vendor-documented coverage, не независимая аттестация. Default TOTALRETURN и вывод current symbol требуют особой осторожности; историю availability нельзя вывести из сегодняшнего update timestamp.

Для личного владельца Windows extraction → authorised private Linux research технически разумен, а cost времени самостоятельной сборки бесплатных данных может превышать subscription. Однако утверждённой пользователем функции полезности/бюджета нет, точный trial runtime не выполнен, полная PIT/vintage доказательность не установлена. Поэтому GO для покупки пока условный и остаётся за владельцем.

Для коммерческого/многопользовательского Alpha OS текущий personal-use FAQ/EULA не подходит: NO-GO для такого использования без подходящих иных прав. Если обязательна бессрочная воспроизводимая база underlying data после прекращения оплаты, retention requirement Norgate также не подходит. Рассмотреть альтернативный договор с явными cloud/retention/derivative правами.

Валидатор и имитационные тесты подтверждают работоспособность некоторых quality gates, а не отсутствие survivorship/look-ahead bias у реального Norgate. Даже 100% coverage при неверном историческом denominator/availability не является доказательством. Строгое исследование ранних предупреждений требует independent membership/event evidence и original availability либо явной маркировки assumptions с ограничением выводов.

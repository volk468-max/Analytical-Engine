# Q001-v1 — Breadth PIT Data Qualification v1

Цель: спроектировать qualified historical SP500/NDX inputs. Гипотеза: Windows NDU + native Python extraction и private Linux validation пригодны для личного исследования при договорной допустимости.
Данные: реальные Norgate exports отсутствуют; изучены официальные docs 2026-11-05; все fixtures вымышлены. Метод: source review, temporal/identity/licence/reference/coverage gates; tests не являются vendor validation.
Результат: спецификация, validator и trial plan; статус real_data_qualified всегда false до отдельной human attestation. Рекомендация NO-GO немедленной покупки, conditional GO на организацию trial; коммерческий/shared use не покрыт personal-use условиями.
Решение владельца: авторизована эта research-задача и Draft PR, не покупка/активация trial/интеграция. Открыто: actual Windows/API trial, original availability evidence, independent historical denominator, identity/actions/retention proof. Следующие шаги — trial-plan с независимой проверкой, без стратегии.
